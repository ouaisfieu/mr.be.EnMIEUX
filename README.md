## 🎯 À propos

<img align="right" src="https://via.placeholder.com/300x200/004a99/ffffff?text=Preview" alt="Preview" width="300">

**MR EN MIEUX** est un site web fan club non-officiel inspiré du design du [Mouvement Réformateur](https://www.mr.be/) belge. Ce projet est une démonstration de développement web frontend moderne avec HTML5, CSS3 et JavaScript vanilla.

### Pourquoi ce projet ?

- 🎓 **Éducatif** : Parfait pour apprendre les bases du développement web
- 🎨 **Design moderne** : Inspiré des tendances actuelles du web design politique
- 📱 **100% Responsive** : Fonctionne sur tous les appareils
- ⚡ **Léger** : Aucune dépendance, chargement ultra-rapide
- 🔧 **Personnalisable** : Facilement adaptable à d'autres projets

## 🚀 Démarrage rapide

### Prérequis

Aucun ! Ce projet utilise uniquement HTML, CSS et JavaScript vanilla. Vous avez juste besoin d'un navigateur web moderne.

### Installation

1. **Clonez le repository**

```bash
git clone https://github.com/ouaisfieu/mr-en-mieux.git
```

2. **Accédez au dossier**

```bash
cd mr-en-mieux
```

3. **Ouvrez dans votre navigateur**

```bash
# Option 1: Ouvrir directement
open index.html

# Option 2: Avec un serveur local (recommandé)
# Si vous avez Python installé:
python -m http.server 8000

# Si vous avez Node.js:
npx serve
```

4. **Visitez** `http://localhost:8000` 🎉

### Déploiement sur GitHub Pages

```bash
# 1. Créez un repository sur GitHub
# 2. Poussez votre code
git add .
git commit -m "Initial commit"
git push origin main

# 3. Allez dans Settings > Pages
# 4. Sélectionnez la branche 'main' et le dossier '/ (root)'
# 5. Votre site est live sur https://ouaisfieu.github.io/mr-en-mieux
```

### Pourquoi pas de framework ?

Ce projet a été volontairement développé sans framework (React, Vue, etc.) pour :

- ✅ Démontrer les capacités du HTML/CSS/JS natif
- ✅ Garantir des performances optimales
- ✅ Faciliter l'apprentissage pour les débutants
- ✅ Éviter toute dépendance externe
- ✅ Assurer une compatibilité maximale

## 🎨 Personnalisation

### Variables CSS

Modifiez facilement les couleurs dans `css/style.css` :

```css
:root {
    /* Couleurs principales */
    --mr-blue: #004a99;           /* Bleu principal */
    --mr-blue-dark: #003366;      /* Bleu foncé */
    --mr-blue-light: #0066cc;     /* Bleu clair */
    
    /* Couleurs neutres */
    --mr-white: #ffffff;
    --mr-gray-light: #f8f9fa;
    --mr-gray: #6c757d;
    --mr-text: #333333;
    
    /* Accent */
    --mr-accent: #FFD700;         /* Jaune/Or */
    
    /* Ombres */
    --shadow-sm: 0 2px 10px rgba(0, 0, 0, 0.05);
    --shadow-md: 0 5px 30px rgba(0, 0, 0, 0.08);
    --shadow-lg: 0 15px 40px rgba(0, 74, 153, 0.12);
    
    /* Rayons de bordure */
    --radius-sm: 8px;
    --radius-md: 15px;
    --radius-lg: 25px;
}
```

### Changer le logo

Remplacez le texte du logo dans chaque fichier HTML :

```html
<!-- Avant -->
<a href="index.html" class="logo">
    <span class="logo-mr">MR</span>
    <span class="logo-plus">+</span>
</a>

<!-- Après (avec image) -->
<a href="index.html" class="logo">
    <img src="assets/images/logo.png" alt="Logo" height="50">
</a>
```

### Ajouter des pages

1. Copiez une page existante
2. Modifiez le contenu
3. Ajoutez le lien dans la navigation de toutes les pages

## 📱 Responsive Design

Le site est optimisé pour tous les écrans :

| Breakpoint | Taille | Appareil |
|------------|--------|----------|
| 📱 Mobile | < 768px | Smartphones |
| 📱 Tablet | 768px - 1024px | Tablettes |
| 💻 Desktop | > 1024px | Ordinateurs |

### Points clés du responsive :

- Menu hamburger sur mobile
- Grilles flexibles (1 → 2 → 3 → 4 colonnes)
- Images fluides
- Typography adaptative
- Touch-friendly buttons
